Implement the Next.js admin dashboard for the ERP.

Requirements:
1. Setup project with:
   - Next.js 15+
   - TypeScript
   - TailwindCSS
   - Shadcn UI
   - React Query
   - Axios
2. Create axios client with tenantId header
3. Create layouts:
   - Admin layout with sidebar and header
4. Pages:
   - /login
   - /products
   - /categories
   - /stock
   - /cash
   - /sales
5. For each page:
   - List data using React Query
   - Modals for create/update
   - Forms using react-hook-form and zod
6. Create POS frontend screen:
   - Product search
   - Cart management
   - Checkout popup
